# FDS-X4 — Pauli Exclusion as Finite Address Protection

## Code
`generate_results.py` generates all 6 deterministic normal-form figures.

## Figures
| File | Description |
|------|-------------|
| `fig1_occupancy_algebra` | Fermionic address protection vs bosonic mode occupation |
| `fig2_address_diversity` | Address diversity under filling with ambiguity cost and verification error rate |
| `fig3_shell_filling` | Shell-filling cartoon showing forced address diversity |
| `fig4_degeneracy_pressure` | Degeneracy pressure normal form |
| `fig5_stability_scaling` | Stability scaling with and without address protection |
| `fig6_address_protection_flow` | Physical dependency chain |

## Data
CSV files with deterministic normal-form values for all figures.

## Requirements
- Python 3.8+
- numpy, pandas, matplotlib
