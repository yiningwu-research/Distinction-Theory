# FDS-X5 — Mathematical Form of Physical Law as Invariant-Form Compression

## Code
`generate_results.py` generates all 6 deterministic normal-form figures.

## Figures
| File | Description |
|------|-------------|
| `fig1_raw_histories_invariant_compression` | Raw histories compressed into invariant/equivariant/covariant sectors |
| `fig2_law_compression_ratio` | Law compression ratio and OOD stability proxy |
| `fig3_symmetry_rule_compression` | Symmetry/equivariance/covariance rule table compression |
| `fig4_semigroup_exponential_compression` | Semigroup and exponential generator compression |
| `fig5_constants_as_invariant_parameters` | Stable parameters vs drifting tracking cost |
| `fig6_wigner_selection_filter` | Wigner selection with FDS bottleneck layers |

## Data
CSV files with deterministic normal-form values for all figures.

## Requirements
- Python 3.8+
- numpy, pandas, matplotlib
