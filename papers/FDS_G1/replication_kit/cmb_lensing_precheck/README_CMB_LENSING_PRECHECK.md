# FDS-G1 `cmb_lensing_precheck`

A self-contained, pre-production CMB-lensing stress-test module for the released
FDS-G1 background/Weyl response normal form.

The package is designed to be copied into:

```text
papers/FDS_G1/replication_kit/cmb_lensing_precheck/
```

It deliberately separates three levels:

1. **Analytic smoke test** — BBKS linear power, Limber CMB lensing, synthetic likelihood.
2. **CLASS-backed precheck** — CLASS linear `P(k,z=0)` plus the registered G1 background,
   growth and Weyl response.
3. **Official ACT DR6 / ACT+Planck PR4 lensing likelihood** — via
   `act_dr6_lenslike`, using `lens_only=True` and the official bandpower covariance.

This is **not** a full Boltzmann implementation of D11. It assumes that the early transfer
function is unchanged and evolves late-time matter power with a scale-independent growth
ODE. It is intended to decide whether the released strict branch has an obvious lensing
amplitude/shape problem before investing in a full CLASS/CAMB perturbation implementation.

## Model conventions

The released replication kit has two equivalent-looking but numerically different response
normalizations. Both are implemented explicitly:

- `normalization: code`

  ```text
  X(a) = 4 chi_H(a) [1-chi_H(a)]
  Sigma-1 = -kappa (3-s) X(a)
  ```

- `normalization: present`

  ```text
  Rhat(a) = X(a)/X(1)
  Sigma-1 = -kappa (3-s) Rhat(a)
  ```

Never mix them in one run. The output metadata records the selected convention.

## Quick start

```bash
cd cmb_lensing_precheck
python -m venv .venv
source .venv/bin/activate
pip install -e .

# Analytic precheck; writes CSV, JSON and figures.
fds-g1-cmb-precheck configs/g1_m34_fiducial.yaml

# Scan the background/Weyl lock.
fds-g1-cmb-grid configs/g1_mkappa_grid.yaml

# Tests.
pytest -q
```

Expected output directory:

```text
outputs/g1_m34_fiducial/
  clpp.csv
  background_growth.csv
  summary.json
  clpp_ratio.png
  sigma_of_z.png
  kernel_diagnostics.png
```

A verified canonical benchmark copy is stored in:

```text
benchmarks/g1_m34_fiducial/
```

Run results are gitignored to avoid repository pollution. Run output must be explicitly
archived outside the git tree.

## CLASS backend

```bash
pip install -e '.[class]'
```

Set in YAML:

```yaml
power:
  backend: class
```

The CLASS adapter obtains a linear present-day LCDM matter spectrum in `Mpc^3`. The G1
spectrum is constructed by applying the growth ratio from a common early-time amplitude.
This is a precheck approximation, not a replacement for a modified Boltzmann solver.

## ACT DR6 and ACT+Planck PR4 lensing

```bash
pip install -e '.[act]'
python scripts/get_act_data.py
```

Then set:

```yaml
likelihood:
  backend: act_dr6
  variant: act_baseline          # ACT only
  # variant: actplanck_baseline  # ACT + Planck PR4
  data_dir: null                 # use package default data location
```

The adapter uses the official convergence-spectrum convention

```text
C_L^kk = [L(L+1)]^2 C_L^phiphi / 4
```

and evaluates the official CMB-marginalized (`lens_only=True`) covariance. It reports the
absolute chi-square and the delta chi-square relative to the matched LCDM calculation.

## Amplitude modes

- `fixed_primordial`: CMB-anchored amplitude diagnostic with a shared primordial normalization;
  not a full primary-CMB likelihood result. This is the appropriate first-pass approximation when
  asking about implications of the locked early-time amplitude.
- `fixed_sigma8`: low-redshift diagnostic normalization that deliberately permits present-day
  amplitude compensation. This corresponds to low-redshift-only fits where sigma8 can drift.

Run both. A large discrepancy between them is itself the compensation channel that primary
CMB is expected to constrain.

## Optional D11 horizon completion

The released G1 likelihood branch is scale independent. The package defaults to:

```yaml
model:
  horizon_completion: none
```

For diagnostics only, the D11-like single-pole factor can be enabled:

```text
F_H(k,a) = c_Gamma^2 k_H^2 / [gamma_Gamma + c_Gamma^2 k_H^2]
```

where `k_H = k/(aH/c)`. This multiplies only `Sigma-1`. Enabling it changes the tested
model and must be reported as a separate branch.

## Generic NPZ likelihood

For an independently exported bandpower data vector, use:

```yaml
likelihood:
  backend: generic_npz
  path: data/my_bandpowers.npz
```

The NPZ file must contain:

- `data`: bandpower vector;
- `cov`: covariance matrix;
- either `window` and `window_ell`, or `ell` for direct interpolation;
- optional string `quantity`: `clpp` or `clkk` (default `clkk`).

A synthetic example is generated by `scripts/make_synthetic_bandpowers.py`. It is only a
smoke test and must never be described as observational evidence.

## Claim boundary

This module can establish a **pre-production lensing tension** under its registered
approximations. It cannot establish full-CMB viability or exclusion because it does not yet
solve the complete D11 perturbation system, primary TT/TE/EE spectra, nonlinear response,
CMB likelihood corrections, or parameter re-optimization against primary CMB.
